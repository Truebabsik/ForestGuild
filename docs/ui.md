# ForestGuild — UI: отряды и вылазки

Статус: черновик v0.1.
Дата: 2026-11-07.
Источники: `design.md` (механика, §4–§10), `architecture.md` (ядро и события), шаг 1 (карта, ростер, UI Toolkit).

## 1. Объём

Экраны полного цикла суток для MVP: **Утро** (состав отрядов и работы), **День** (вылазка по часам
с паузами и решениями), **Вечер** (разбор добычи), **Ночь** (отчёт леса). Плюс постоянный HUD.

Не входит в этот документ: станций и крафта (step 3+), экономика каравана, экран сердца леса,
детальный арт (используются заглушки в стилистике шага 1: тёмные панели, золото, «бумага» карточек).

## 2. Принципы

1. **Приказ и подпись.** Отправка отряда — не кнопка «играть», а *подпись под приказом*: игрок видит
   итоговый документ (кто, куда, зачем, с какими числами) и подтверждает его. Следствие: составление
   отряда и отправка — два разных действия; подтверждение всегда показывает сводку и предупреждения.
2. **Состав — отдельная комната.** Сборка отряда — сосредоточенная работа с иконками людей, и она
   живёт на отдельном экране «Сбор отряда»; доска приказов только отправляет готовые отряды.
   Следствие: на доске минимум действий (зона + намерение + подпись), все перетаскивания — в одном
   месте, а состав отряда сохраняется между днями как живой пресет.
3. **Время всегда на виду.** Главный ресурс — 10 рабочих часов, и игрок должен видеть, как их съедает
   дорога. Следствие: при выборе зоны сразу показывает раскладку «дорога → работа → дорога»; часы,
   за которые уйдёт вылазка, видны до отправки, а не по ходу.
4. **Число — это выбор.** Ни один показанный счётчик не должен быть «просто инвентарём».
   Следствия: у кристалла на карте — срок жизни и подпись «увезёшь — зона ляжет голодной»;
   у мешка — «что не унесём, то нашли зря»; у ростера — «этого человека не выучить заново».
5. **Необратимость без маскировки.** Смерть и брошенный раненый не прячутся в лог: карточка события
   остаётся в потоке дня и попадает в вечерний разбор, красным. Отмена невозможна — UI это не имитирует.
6. **День не кликер.** Часы тикают сами, паузы — только на решениях (design.md §13, пункт 5). Следствие:
   проигрыватель с пуск/скорость/«до следующего события», а не кнопка «следующий час».
7. **Предупреждать, а не запрещать.** UI блокирует только то, что запрещено миром (чистка без
   храбрых, мёртвый в отряде), всё остальное — предупреждение с объяснением цены.
8. **Имена вместо сводов.** В логах днём и ночью люди и твари называются по именам, причины —
   вслух: «Каменный лог: тварь не наелась — к утру уйдёт к деревне», а не «миграция: 1».

## 3. Каркас

**Стартовое меню.** «ЛЕСНАЯ ГИЛЬДИЯ» — список пунктов **из `scenarios.csv`**: «НАЧАТЬ ИГРУ»
(обычный цикл с дня 1), «СБОР ОТРЯДА (ТЕСТИРОВАНИЕ)» — экран Сбора напрямую, «ПОХОД В ЛЕСУ
(ТЕСТИРОВАНИЕ)» — два отряда сразу в лесу. Каждый пункт запускает свой эпизод: свой мир, свой сид,
свой стартовый экран; при `on_finish=menu` эпизод возвращает в меню, при `continue` идёт в цикл.
Добавить проверочный эпизод («день 15, все ранены») — это строка в таблице, без компиляции.

Одна сцена, пять состояний + постоянный HUD. Цикл всегда вперёд: Утро → День → Вечер → Ночь → Утро…
Промотать фазу нельзя (Утро можно «закрыть» не назначив). «Сбор отряда» — отдельный полноэкранный
режим, доступный **только из Утра**: доска в это время ждёт, пока не вернёшься с составом.

| Экран | Состояние ядра | Что делает игрок |
|---|---|---|
| Начало дня | `World` (люди, раны, смерти) | читает номер дня и статус жителей, жмёт «НАЧАТЬ ДЕНЬ» |
| Доска приказов (Утро) | `DayPlan` (составы собраны заранее) | зона и намерение отряда, работы в деревне, «НАЧАТЬ ДЕНЬ» |
| Сбор отряда | `DayPlan` (состав одного отряда) | перетаскивает людей в лоток, задаёт наказы |
| Поход | `ExpeditionSim`, события по часам | отвечает на развилки (или наказы решают) |
| Разбор (Вечер) | склад + отчёт дня | распределяет постели, закрывает день |
| Лес (Ночь) | `NightSim` → `NightReport` | читает отчёт, жмёт «УТРО» |

Горячая перезагрузка таблиц (`R`) показывает тост «Таблицы обновлены на границе дня» — ошибка
валидации оставляет старые таблицы и показывает красный оверлей с `файл:строка:колонка`.

Поверх всех экранов работает **Досье зоны** (§4.7) — оверлей-справка, не фаза: имя зоны в любом
месте UI кликабельно и открывает досье.

## 4. Утро — доска приказов и сборка

Два экрана. Доска — *пульт отправки*: смотрит на два готовых отряда и раздаёт им «куда» и «зачем».
Сбор — *мастерская состава*: отдельный экран, где таскаются иконки людей.

### 4.1 Доска приказов (каркас экрана, 1280×720)

```
┌ ДЕНЬ 4 · УТРО · частокол 6/10 · до волны: 17 · склад: Обсидиан 1 · здоровы 7/8 ┐
│ ОТРЯДЫ                             │                                          │
│ ┌ ОТРЯД «А» ──────────────────────┐ │                                          │
│ │ зона: [Вулканические ключи ▾]   │ │                                          │
│ │ дорога 1 ч · в лесу 8 ч         │ │              К А Р Т А                   │
│ │ [Брунни] [Скади]      [портреты]│ │   Опушка ─ Ключи ─ Топь                  │
│ │ [намерение: сбор] [настроить…]  │ │      \      │      /                    │
│ └─────────────────────────────────┘ │       Чаща ─ Лог ─ Сердце                │
│ ┌ ОТРЯД «Б» ──────────────────────┐ │                                          │
│ │ зона: не выбрана ▾              │ │   (клик по зоне — досье §4.7)            │
│ │ никого — жми «настроить…»       │ │                                          │
│ │ [намерение: сбор] [настроить…]  │ │                                          │
│ └─────────────────────────────────┘ │                                          │
│ ⚠ «Б»: в лес никто не идёт                          [ НАЧАТЬ ДЕНЬ ]              │
└──────────────────────────────────────────────────────────────────────────────────┘
```

- Слева — две **карточки отрядов-пресетов** (§4.2): зона-переключатель, портреты состава, время
  дороги, намерение, «настроить…». Пустой отряд прямо говорит, что людей нет.
- Справа — **карта**: клик по зоне открывает досье, клик по деревне — окно работ (§13).
- Внизу — сводка предупреждений дня и одна кнопка «НАЧАТЬ ДЕНЬ» (§4.8).
- Работы в деревне и свободные люди на доске **не живут**: работы — в окне деревни, люди — в Сборе.
  На доске только готовые отряды.

### 4.2 Отряд — живой пресет

- Отряд — сущность, живущая **между днями**: состав и наказы сохраняются. Утром пресет «просыпается»:
  состав пересчитывается на состояние людей — мёртвый выпал с красной меткой, раненый числится,
  но в лес не выйдет.
- Имена — «А» и «Б» (в MVP два отряда); игрок всё равно думает по составу.
- Состав меняется в любой момент до подписи — кнопка [настроить…] открывает Сбор (§4.3).
- Наказы (§5.5) — часть пресета отряда: задаются в Сборе, на доске не редактируются. Доска решает
  «куда», Сбор — «кто и по каким правилам».

### 4.3 Сбор отряда — отдельный экран (drag & drop)

```
┌ СБОР ОТРЯДА «А» ──────────────────────────────────────────────────────────────────┐
│ СВОБОДНЫЕ ЛЮДИ (5)                     │ ОТРЯД «А»                                │
│ ┌───────┐ ┌───────┐ ┌───────┐          │ ┌────────────┐ ┌────────────┐ [ + слот ] │
│ │Брунни │ │Скади  │ │Лея    │          │ │ Брунни     │ │ Лея        │           │
│ │ох 4   │ │ох 3   │ │сб 3   │  драг →  │ │ох 4 · храбр│ │сб 3 · зорка│           │
│ │храбр  │ │зорка  │ │терпел.│          │ │ [охраняю▾] │ │[собирает▾] │           │
│ └───────┘ └───────┘ └───────┘          │ └────────────┘ └────────────┘           │
│                                        │ слоты 8/12 · работа 3 ч · встречи ×1,0   │
│ ЗАНЯТЫЕ (приглушены)                   ├ НАКАЗЫ НА ВЫЛАЗКУ ───────────────────────┤
│ Тове — в отряде «Б»; Хильда — постель  │ встреча [спрашивать▾] туша [спрашивать▾] │
│                                        │ раненый [спрашивать▾] мешок [спрашивать▾]│
│                                        │                               [ ГОТОВО ] │
└───────────────────────────────────────────────────────────────────────────────────┘
```

- **Слева** — иконки людей. Свободные — цветные, таскаются. Занятые другим отрядом или работой —
  приглушены с подписью «в отряде „Б“»: сразу видно, кем дорожим; таскать их нельзя.
- **Справа** — лоток по числу слотов отряда (4): занятые показывают портрет, навык, роль и «×»,
  пустые подписаны «свободно». Человек убирается крестиком.
  Человек в лотке показывает навык, черты и (охотник) переключатель `охраняю / собираю /
  иду по следу` (design.md §8.2), по умолчанию — «охраняю».
- **Во время драга** лоток подсвечивается, когда над ним завис человек, — видно, куда он встанет.
- **Наказы** — четыре селектора (§5.5), по умолчанию «спрашивать»: день тогда останавливается на
  каждой развилке. «ГОТОВО» сохраняет пресет и возвращает на доску; отдельной кнопки
  «распустить» нет — человек убирается из лотка крестиком, по одному.
- Основной жест — драг; запасной — клик-клик (выбрать карту → клик по слоту) для быстрого прохода
  и доступности. Драг в UI Toolkit требует заметной работы (PointerCapture, стили), клик-клик
  дешевле и обязателен как минимальный путь в шаге 2.
- Мёртвые не показываются списком слева: их табличка снизу («погибли: …») — ростер помнит всех.

### 4.4 Карточка жителя

Иконка-карта используется в двойной роли: в ростере на доске (мелкая, «иконка + имя + класс») и
в Сборе (развёрнутая). Содержание:

| Элемент | Содержание | Откуда |
|---|---|---|
| Имя, класс | «Скади · охотник 3» | `roster.csv` + `professions.csv` |
| Полоса навыка | `Охота ●●●○○` — только растущие для класса | `skills_override` + `skills_allowed` |
| Черты | «Храбр · Крепкий» (чипы) | `traits.csv` |
| Состояние | здоров / **ранен (постельный режим)** / мёртв (серым, в конце списка) | состояние жителя |
| Слоты, здоровье | «4 слота · ●●●●» | `tuning.csv`; здоровье — `combat_tuning.csv`, растёт ночью и в постели |

Правила отображения:

- Мёртвые **не исчезают**: приглушённая карточка в конце списка и строка «погибли: …» в Сборе.
  Невозобновимый ресурс должен оставаться виден.
- Раненый в Сборе таскается с подписью «лечится — встанет утром»; на доске он виден в
  работах как пациент постели.
- Полные навыки и модификаторы — в тултипе карты; на самой карте только то, чем человек влияет
  на состав отряда прямо сейчас.

### 4.5 Строка итогов отряда

Живёт и на доске, и в Сборе, пересчитывается мгновенно — это сердце обоих экранов:

| Показатель | Пример | Правило |
|---|---|---|
| Часы в лесу | «дорога 1 ч → работа 8 ч → дорога 1 ч» | 10 ч − 2 × дорога; у сердца остаются считанные часы |
| Слоты | «7/12» | 4 × люди (+1 за «Крепкий») |
| Встречи | «×1,0 → ~8%/час» | 25% × плотность × множители (люди сверх двух, намерение, тревога зоны, груз на обратном пути). В примере плотность 0,33 (1 тварь на 3 еды) |
| Охрана | «+1 к бою, −20% к засаду, +20% к отходу» | есть хоть один охотник «охраняю» |
| Прогноз находок | «~2 за вылазку» | часы × находки/час каждого собирателя (§5.3 design.md) |

Предупреждения отряда (видны и на доске, и в Сборе; не блокируют, кроме отмеченных ✕):

| Когда | Текст |
|---|---|
| Состав неполон утром | «Отряд неполон: {имя} погиб / ранен — собрать заново» |
| Отряд пуст, а подпись нажата | ✕ «Отряд никого не идёт» |
| Один человек | «Один в лесу: охраны нет» |
| Третий человек | «Втроём в лесу шумно — твари замечают раньше» |
| Второй отряд идёт в ту же зону | «Сольются в один: считай как один отряд» |
| Пояс (5 ч дороги) | «До темноты успеем немного — см. §5.6» |
| Намерение «чистка» без храброго | ✕ «На тварей без храбрых не ходят» |
| Зона в тревоге | «Вчера шумели — зверь настороже» |
| Неосвоенная зона | (предупреждения нет — зона просто не разведана) |

### 4.6 Работы в деревне

Три стока рабочей силы; люди ставятся кнопками [+/–] рядом с каждой работой (драг на доске
не используется вообще — он только в Сборе):

- **Починка частокола.** «+2 прочности за человеко-день». Показывает текущую прочность и сколько
  человек стоит на стене; лишних снимает, когда прочность дошла до 10.
- **Лечение.** Постели назначаются вручную: имя раненого → «здоров к утру». Постелей
  мало, раненых может быть больше — кто не получил постель, ждёт вечернего разбора.
- **Заготовка.** +1 подножного корма в пристройку склада за человеко-день (число — гипотеза,
  тюнинг в `tuning.csv`).

### 4.7 Досье зоны — отдельный экран-справка

Карточка зоны из design.md §6.2 — девять плотных блоков; в мелкой панели селектора она не читается.
Поэтому зона имеет **досье** — полноэкранный оверлей, открывающийся по клику на имя зоны из любого
места (карточка отряда на доске, селектор, шапка колонки Похода, строки Ночи, кнопка на карте).
Это не фаза суток: поверх Утра/Вечера/Ночи открывается без паузы, поверх Похода —
тик останавливается на время чтения (игровое время не тратится).

В селекторе зоны — короткая выжимка (дорога, последняя сводка, настроение зоны) и кнопка
«ПОДРОБНЕЕ →» на досье; из досье кнопкой «К СБОРКЕ» зона выбирается и отряд назначен.

```
┌ ДОСЬЕ ЗОНЫ · ВУЛКАНИЧЕСКИЕ КЛЮЧИ ──────────────────────────────────────────────┐
│ ┌──────────────────────────── картинка 640×360 ────────────────────────────┐    │
│ └──────────────────────────────────────────────────────────────────────────┘    │
│ окраина · соседи: Опушка, Топь, Каменный лог · дорога 1 ч                     │
│────────────────────────────────────────────────────────────────────────────────│
│ Земля дышит жаром: из трещин сочится оранжевый свет, над ключами дрожит воздух. │
│ Дышать тяжело, вода обжигает даже сквозь кожу.                                  │
│                                                                                 │
│ КТО ВОДИТСЯ  искромёты — быстрые ящерицы, что плюются огнём; костяные бегуны     │
│              в броне из наростов                                                │
│ ЧТО НАЙТИ    крапива, что жжётся сквозь ткань · пепельный лишай · стеклянница ·  │
│              обсидиановая руда · серные натёки                                   │
│ СРЕДА        взвесь — выносливость тает быстрее; зелья портятся                  │
│ ОСОБОЕ       всё добытое нагрето: портит зелья и выдаёт отряд на обратном пути   │
│────────────────────────────────────────────────────────────────────────────────│
│ СЛУХИ        день 3 — отряд столкнулся с искромётом, отошли                      │
│              день 4 — видели следы чего-то крупного                              │
│ сейчас       неспокойно                                                          │
│                                     [ ← НАЗАД ]         [ К СБОРКЕ ЭТОЙ ЗОНЫ ] │
└────────────────────────────────────────────────────────────────────────────────┘
```

Правила досье:

- **Точных чисел нет.** Игрок не видит «твари: ×1, кристаллов 1» — только слова «тихо / следы /
  неспокойно / гнездо» и слухи. Числа показываются лишь в отладочном режиме (тумблер в HUD).
- **Слухи — единственный источник деталей.** Последние четыре записи `ZoneState.Sightings`
  («день 3 — отряд столкнулся с искромётом, отошли»). Слух появляется, когда отряд вернулся
  и рассказал; неразведанная зона слухов не имеет.
- **Динамическое — сверху, статика — снизу.** Слухи и настроение зоны — из мира; описание, кто
  водится, находки, среда и особое правило — из `zone_lore.csv` (`zone_id; field; text`).
- **Картинка** — `Assets/UI/Art/Zones/<zone_id>.jpg`, 640×360, обрезается по ширине карточки.
- **Подсказка про кристалл** живёт не в досье, а в карточке зоны словами: «если вынести всё,
  зона обеднеет и твари пойдут к деревне» — без чисел.
- **Кто что заметит** — пометки классов в «ЧТО НАЙТИ» (сборщик/охотник; руда с ×0,5) и «иду по
  следу» охотника подсказкой в «КТО ВОДИТСЯ»: «след здесь найдёт гнездо/подходы».
- Точка входа определяет выход: из селектора — «К СБОРКЕ ЭТОЙ ЗОНЫ» (действие), из Похода/Ночи —
  только «НАЗАД» (справка).

### 4.8 Начать день

Кнопка «НАЧАТЬ ДЕНЬ» открывает модал — сводку приказа перед отправкой:

```
┌ ПРИКАЗ НА ВЫЛАЗКУ ─────────────────────────────────────────────────────┐
│ ОТРЯД «А» → Вулканические ключи · сбор                                 │
│ Скади (ох 3, охраняет) · Брунни (ох 4, охраняет) · Лея (сб 3)          │
│ дорога 1 ч · в лесу 8 ч · втроём шумно                                 │
│ ⚠ втроём в лесу шумно — твари замечают раньше                          │
│ ОТРЯД «Б» → Опушка · сбор · … (свёрнуто)                                │
│ В ДЕРЕВНЕ: 1 на частокол (+2) · 1 на постель · 3 свободны              │
│                                                                        │
│        [ НАЧАТЬ ДЕНЬ ]                      [ НЕ ПОКА, ДОПОЛНЮ ]       │
└────────────────────────────────────────────────────────────────────────┘
```

Смысл: игрок читает **итог одним взглядом**; все предупреждения дня собраны тут, поэтому неизвестности
нет. «НЕ ПОКА, ДОПОЛНЮ» возвращает на доску. После подписи — экран Похода.

## 5. День — поход

### 5.1 Хронометраж

Часы тикают сами (интервал ~0,7 сек при ×1). Любое событие-развилка ставит паузу. Стартовое состояние —
на паузе раз в час до первой развилки; далее после развилки играет дальше до следующей. Скорости:
`×1`, `×2`, `к следующему событию`, `домотать все часы без пауз` — последнее допустимо, потому что
у каждого отряда есть наказ (§5.5): если наказ «спрашивать», доматывание останавливается на каждой развилке.

Оценка времени: сам тик — секунды (10 часов × 0,7 с ≈ 7 с), «1–2 минуты» из §11 — это тик **плюс чтение карт
и обдумывание решений**. Если день проходится за секунды без чтения — это нормально, а не баг.

### 5.2 Каркас экрана

```
┌ ДЕНЬ 4 · ДЕНЬ · частокол 6/10 · до волны: 17 · склад: Обсидиан 1 · здоровы 7/8 ┐
│ ПОХОД · Вулканические ключи                                осталось 420 мин │
│ ┌────────────────────────────────────────────────────────────────────────────┐ │
│ │ · отряд «2»: Вулканические ключи · Брунни, Скади                           │ │
│ │ · Брунни нашёл: Огненная крапива                                            │ │
│ │ · Скади нашёл: Обсидиановая руда                                            │ │
│ └────────────────────────────────────────────────────────────────────────────┘ │
│ ┌ ВСТРЕЧА: Костяной бегун ──────────────────────────────────────────────────┐  │
│ │ Вулканические ключи: тварь рядом. Дальше — как решит отряд.               │  │
│ │ [спрятаться · как повезёт] [отойти · надёжно] [бой · почти наверняка]      │  │
│ └────────────────────────────────────────────────────────────────────────────┘  │
│                                                [ ДОМОТАТЬ ]  [ ПАУЗА ]          │
└──────────────────────────────────────────────────────────────────────────────────┘
```

- **Сейчас**: счётчик часов, живой лог и карточка развилки с вариантами и ценой; часы идут
  сами и останавливаются только на решении. Наказы отряда (§5.5) снимают паузу — тогда карточки нет.
- **Цель шага 2.5**: ось часов с полосами отрядов, две колонки сразу, скорости ×1/×2 и «к следующему
  событию». Сейчас отряды идут по очереди, а вместо оси — счётчик.

- **Цель по каркасу** — ось часов с полосами отрядов сверху, по строке-колонке на отряд
  (активная развилка разворачивается, остальные сворачиваются в титульную строку с зоной,
  выносливостью и слотами), внизу проигрыватель. Сейчас отряды идут по очереди, а ось заменяет
  счётчик «час N из M».

### 5.3 Поток отряда

Строки лога с часами слева (целые часы; дорога тоже пишет «в пути»). Каждая строка суффикс-причины:
«Находка: стеклянница (Тове) — заняла 0,5 слота». Полосы состояния в шапке колонки:
- выносливость каждого человека (4 точки, ноль — сереть);
- слоты груза (заполнение с подписями последнего предмета);
- строка встреч текущего часа.

Событие отмечается галкой на оси часов и остаётся в логе после решения — итог развилки читается
в контексте («12:00 ВСТРЕЧА → отошли, бросили 1 мешок»).

### 5.4 Карты событий

Все карты семантически одинаковые: заголовок (кто/что/где), тело (что происходит), варианты-кнопки
с *ценой*, внизу пункт «наказ» из §5.5.

**Встреча** (`Encounter`): модальное окно поверх похода — сверху арт твари в поиске (`<art>_search.jpg`),
под ним «ВСТРЕЧА: имя», строка последствий и три кнопки: `спрятаться / отойти / бой` со **словом о риске**
вместо процента («почти наверняка», «надёжно», «как повезёт», «рискованно»). Текст карточки объясняет цену:
«Проскочить — тихо, если повезёт. Отойти — час долой. Бой — туша или рана». Пороги слов заданы в ядре
(`Expedition.RiskWord`), цифры не показываются нигде.

**Туша после боя** (`Killed`): тот же модал, но с артом `<art>_dead.jpg` — заголовок «ТУША» и
`утащить целиком (3 слота) / освежевать — <имя · мастерство> / бросить`.
На кнопке разделки стоит тот, кто в отряде лучше всех владеет ножом, и его степень мастерства словами:
«Хильда · умелый», «Брунни · мастер», «новичок», «виртуоз» (`Expedition.MasteryWord`). Цена — только
то, что игроку нужно решить: сколько мест займёт и чьими руками. Что нашлось в туше, пишется **после**
выбора, в логе («освежевали: кристалл и части в мешке»).

**Полный мешок** (`Found` при полном мешке): «МЕШОК ПОЛОН» — «взять вместо <самая дешёвая находка>» (если новая дороже) или «не брать». Наказ «мешок» снимает карточку: `заменять` выбрасывает дешёвое сам, `не брать` молча бросает.

**Раненый** (`wounded`): «Скади ранена. Несём: 3 слота, дорога +1 ч, отход −20%. Оставим — она не
дойдёт сама: умрёт до утра.» Два варианта: `нести` / `оставить` (второй — красный, подтверждение
вторым кликом, отмена невозможна). Это главное решение игры: карточка занимает весь разворот
колонки, всё остальное тускнеет.

**Выносливость 0**: не развилка, а событие-«авто»: «Выносливость на нуле: боёв нет (−30%), отряд
разворачивает домой». Лог продолжает дорогу назад.

**Мёртвый** (`death`): «Скади погибла. Карточка останется в разборе.» Лог красным; никаких «закрыть
и забыть».

### 5.5 Наказы — политика на развилки

Чтобы день можно было домотать и чтоб консольный `tools/sim` гонял тот же код, политика решений —
**передаваемый объект в ядре**, а не UI-костыль:

```
StandingOrders {
  Encounter:  ask | hide | retreat | fight
  Carcass:    ask | haul | butcher | leave
  Wounded:    ask | carry | leave
  BagFull:    ask | replace_cheapest | skip
}
```

- По умолчанию все поля `ask` — день останавливается на каждой развилке.
- Наказы задаются при сборке отряда (§4.3, панель «НАКАЗЫ НА ВЫЛАЗКУ»): фантазийно это «приказ,
  данный на пороге леса» — глава гильдии не может идти с каждым отрядом. Менять наказ можно прямо
  в Походе (это игровое решение: перекрутить политику, пока отряд в лесу).
- Наказ, отработавший развилку, пишет в лог «по наказу: отошли» — игрок видит, чем пожертвовал
  отряд, и может вернуть наказу режим «спрашивать».

Открытый вопрос: наказы — MVP или step 2.5 (для баланс-прогонов `sim --days 21` нужен уже `fight`
и т.д., но без UI).

### 5.6 Часов не хватило: пояс, сердце и ночёвки

Бюджет 10 ч. Пояс (5 ч дороги туда-обратно) оставляет 5 ч работы, но выносливость отряда обычно
кончается раньше — на двух-трёх людях это 8–12 часовых шагов. Сердце забирает 8 ч дороги, и работать
там почти некогда. В момент, когда отряд упирается в остаток дня, карта событий:
`вернуться сегодня (работы было мало) / остаться с ночёвкой (завтра вторая половина вылазки)`.

В **MVP** работает только первый вариант: пояс открыт и даёт короткую работу, сердце — почти пустой день,
и это честное следствие правила «10 часов». Ночёвка — вне MVP (§12.1).

## 6. Вечер — разбор

```
┌ ДЕНЬ 4 · ВЕЧЕР ──────────────────────────────────────────────────────────────┐
│ ИТОГ ДНЯ                                                                    │
│  Отряд «А»: добыто 4 ед. · 1 тварь убита · встреч 2 · все вернулись          │
│  Отряд «Б»: добыто 2 ед. · встреч 0 · Скади ранена — постель                  │
│ СКЛАД (было → стало)               ПОСТЕЛИ             ЧАСТОКОЛ 6/10         │
│  травы 0 → 2    огн. крапива 2     [Скади ✓ на лечении]  стена не ест лут    │
│  руда  0 → 1    обсидиан 1         (Хильда: ждёт постели)  +2 — рабочей       │
│  туши —         кристалл 1                            силой утром            │
│ [ В КАБИНЕТ — СПАТЬ ]                                                       │
└──────────────────────────────────────────────────────────────────────────────┘
```

- Добыча предварительно разложена по умолчанию — «всё в запас» (кристаллы всегда
  в запас; частокол в MVP ест только рабочую силу, не материалы). Переназначение строки — клик.
- Слева направо — три счётчика склада с **дельтой дня** (+2), чтобы день ощущался оборотом, а не стопкой.
- Постели: раненые, получившие место, — «✓ здоров к завтра»; не получившие — красная причина:
  «Постели кончились. Можно послать второго на постель вместо Тове — она тогда перейдёт в заготовку».
- Кнопка «СПАТЬ» закрывает вечер; предупреждает, если есть необработанная добыча.

## 7. Ночь — лес

Оверлей поверх карты со строками события ночи, каждая с причиной и следствием именовано. Строк —
**не больше шести**: зоны без событий сворачиваются в одну строку «в прочих зонах тихо», гнёзда и
миграции идут отдельными.

```
┌ НОЧЬ ──────────────────────────────────────────────────────────────────────┐
│ Твари ели:                                                                  │
│  Вулканические ключи: наелись, но одна бродит голодная.                     │
│  Голодная уйдёт к деревне: КАМЕННЫЙ ЛОГ → ВУЛК. КЛЮЧИ                       │
│  (приграничная зона — иначе бьёт частокол).                                  │
│ Кристаллы: один «стёк» в землю — лежал свои два дня.                        │
│ Гнёзда: в Каменном логу гнездо растёт — скоро ещё одна тварь.               │
│ До волны: 17 дней.                                                          │
│                                          [ ВСЛЕД ЗА НОЧЬЮ — УТРО ]          │
└──────────────────────────────────────────────────────────────────────────────┘
```

Точных чисел в Ночи нет — только причины и следствия («одна не наелась», а не «1 из 2»).
Отладочных счётчиков тоже нет: режим чисел убран (§4.7).


- Карта подсвечивает маршруты миграции стрелками по графу соседей — **отменено**: ночь объясняет
  словами, а не картой. Имена зон в строках отчёта кликабельны — открывают досье (§4.7).
- Формулировки — **8–10 шаблонов строк**, список проявляется построчно, без звука: это
  «обещание лес живой» и главный носитель причинности (design.md §13, пункт 1).
- Волна (день 21+): в ночном оверлее — красный блок «ВОЛНА»: «К деревне идут: 2 твари», «Охотники
  у стены сбили: 1», «Частокол: −4 (осталось 6/10)», «Отбились» или «Пробились в деревню. Погибли: …».
  Реализовано: `WaveSim` в ядре и красные строки в `ShowNight`.

## 8. HUD и формат чисел

Постоянная строка (верх, сжатая; в Походе — только «до волны» справа):

`ДЕНЬ 4 · УТРО | частокол 6/10 | до волны: 17 | склад: травы 2 · руда 1 · кристалл 1 | здоровы 7/8`

Форматы: множители с запятой («×1,2»), слоты «16», выносливость точками.
Часы лога — 09:00…15:00 (косметика, внутри — целые часы 1–6).
Всё, что применилось ночью или днём, — подсветка дельты: числа меняются с миганием, а не «просто новые».

## 9. Данные ↔ UI

| Событие/состояние ядра | Где показывается |
|---|---|
| `DayPlan` (составы, наказы) | Доска приказов (§4.1) и Сбор (§4.3) |
| `Hour` (1–10), дорога/работа | Счётчик часов и лог похода |
| `Found` | лог похода; переполнения пока не спрашивают — находка просто не влезает |
| `Encounter` | карта встречи с вариантами и ценой |
| `Killed` | карта туши + трофей в лог |
| Ранение (обратный вариант боя) | карта раненого → постель в Вечере |
| `Migrated`, `NestBorn`, еда, кристаллы | Ночь: текстовый отчёт, зоны в строках кликабельны |
| `ZoneState.Scouted` | «?» в панели зоны |
| `ZoneState.AlertDays` | предупреждение в лотке и строка встреч |
| `ZoneState` → настроение зоны и слухи | Доска слов «тихо / следы / неспокойно / гнездо» и блок «СЛУХИ» в Досье (§4.7). Точных чисел в обычном режиме нет |
| `zone_lore.csv` (описание, кто водится, находки, особое) | Досье зоны, статические блоки (§4.7) |
| Полоса частокола, срок волны | HUD; починка — в Работах и Вечере |

Правило: UI не считает шансы и не показывает их — бросок делает ядро, игрок видит цену варианта и того, кто поведёт.
Предупреждения отряда тоже считает ядро («сухой прогон приказа» → список проблем), чтобы правила
предупреждений не разъехались между симом и UI: `tools/sim` гоняет те же проверки.

## 10. Реализация в Unity (UI Toolkit)

- Всё остаётся в `Assets/Scripts/Game` + `UI/*.uxml/uss`, как в шаге 1. Никакого NGUI/DOTS.
- Экраны — отдельные классы, `MapScreen` только переключает фазы (ADR-0003): `StartOfDayScreen`,
  `MorningBoard` (планирование), `MusterScreen` (Сбор), `EveningScreen`, `DossierScreen`, `HudView`.
  Шаблоны карточек и логов пока строятся кодом; выделять `EventCard`/`LogLines` — по мере роста.
- Драг иконок в `Muster` — ручной манипулятор с захватом указателя (PointerCapture) и стилями
  «тянется/принимает»; клик-клик — обязательный запасной путь того же обработчика.
- Стиль: панели и кнопки — по мотивам кита из `ext/` (палитра в `Map.uss`, золотая плашка
  `UI/Art/Kit/plate.png` под заголовки). Кнопки кита картинками не берём: подписи в них запечены.

- USS: токены цветов/отступов в `ui-theme.uss`, темы «панель/карта/критично»; заглушки-иконки
  прямоугольниками с классом `slot-icon` — арт подключается позже заменой спрайтов.
- 1920×1080 фиксированной вёрсткой (PanelSettings, ScaleWithScreenSize, Match 0.5), трёхколоночная сетка Утра и колонки Похода — «flex».
- Пауза Похода: ядро возвращает `List<Event>`-пакет за час; бегун `ExpeditionRunner` в Game выполняет
  пакеты корутиной (только Unity-таймер, вся логика — в Core), остановленная развилка — модальный
  `StyleSheet: none`-оверлей над колонкой отряда.
- Вся генерация строк лога — по шаблонам в одном статическом классе `LogLines` (одно место для
  правки формулировок, их будут крутить по эксплуатации).

## 11. Чем UI доказывает MVP (design.md §13 → экраны)

| Доказательство | Где живёт в UI |
|---|---|
| Игрок понимает, откуда угроза | Тексты причин в Ночи (§7) и кликабельные зоны отчёта |
| Сбор кристалла — выбор | Счётчик кристаллов + подсказка «увезёшь — голодная» (§4.7), «стёк» в Ночи |
| Бросить тушу/раненого | Карты туши и раненого, цены видны прямо (§5.4) |
| Чистка меняет волну | Один бросок волны против частокола и охотников в деревне (§7) |
| День за 1–2 минуты | Хронометраж + наказы (§5.1, §5.5): 2–3 паузы на день, остальное доматывается |

## 12. Открытые вопросы

1. **Ночёвка в поясе.** Как ночной тик леса царапает лагерь (встречи? расход выносливости?) —
   пока открыто и в механике; UI зарезервировал карту «вернуться / остаться» (§5.6).
2. **Постели.** Сколько их и лечатся ли травами — блокирует дизайн Работ и Вечера (сейчас: 1–2 вручную).
3. **Наказы.** MVP или step 2.5; в каком виде для `sim --days 21` (§5.5).
4. **Волна.** Экран-минимум (один бросок) или полноэкранная сцена с частоколом — небольшой шаг 2.5.
5. **Иконки зон и портретов.** Живут заглушками (портреты — сгенерированные картинки), сколько стилей нужно для спрайтов — открытый вопрос.
6. **Два отряда в одной зоне.** Сообщение о слиянии есть; показывать ли их одной колонкой после
   слияния — удобнее, но теряется парность. Считаю: да, одной, с чипом обоих отрядов.
7. **Пресеты и сейвы.** Отряды-пресеты (состав + наказы) — сущности в сейве, как жители; составы
   не сохраняются, если день уже идёт. Что показывать игроку, погружающемуся в сохранение посреди
   Похода, — вернуть в момент сохранения, пресеты пересчитать на живых.
8. **Тексты досье.** Решено: отдельная таблица `zone_lore.csv` (`zone_id; field; text`, поля
   `look / beasts / finds / special`), см. `design.md` §6.5. Слухи — не таблица, а `ZoneState.Sightings`
   в мире. `tools/sim` тексты не читает, но проверяет, что на каждую зону есть все четыре поля.

## 13. Деревня — окно работ

Клик по деревне на карте открывает окно работ: частокол с прочностью, «починка / постели / заготовка»
с кнопками [+/−], список «кто где» и «ГОТОВО». Работы больше не живут на экране планирования —
там только отряды. Реализовано в `VillageScreen`.
