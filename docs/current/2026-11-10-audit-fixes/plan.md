## Фазы

### Ф1. Походные штрафы и −3 слота (T8)

Сейчас: раненый идёт как здоровый, выбитого несут за 60 минут и без слотов; ключи `wound_*`, `hurt_*`,
`carry_out_*` лежат в `combat_tuning.csv` без читателей.

- **Скорость дороги:** обратный путь (и остаток пути) делится на скорость отряда. Скорость = минимум по людям:
  здоровый 1.0, ранен (<50 %) `wound_speed_mult`, тяжело ранен (<25 %) `hurt_speed_mult`, несут выбитого —
  `carry_out_speed_mult`. Дорога в минутах умножается и округляется вверх.
- **Слоты:** доступные слоты отряда = `slots_per_person` × люди, минус `carry_out_slots` за каждого выбитого,
  минус `carry_carry`-доля грузоподъёмности раненого (`wound_carry_mult`, `hurt_carry_mult`).
  Проще и честнее: слоты считаются по людям с их множителями: здоровый 1.0, ранен <50 % — `wound_carry_mult`,
  тяжело ранен <25 % — `hurt_carry_mult`, несут — 0 слотов у этого человека, плюс −`carry_out_slots` общих.
- Принять решение по формулировке «−3 слота»: списывать из общего пула при переноске.
- **Проверки:** «wounded move slower», «carrying the downed costs slots», «no penalty on the boundary»,
  «поход с выбитым заканчивается позже, чем без него».
- Документы: `design.md` §8.3, ADR-0043 снять пометку «не реализовано».

### Ф2. Кормление по `food_need` и вес вида в стае

- `beasts.food_need` сейчас не читается: удильщик и болотник по описанию едят больше. `NightSim` кормит по 1.
  Читать `food_need`, голод/миграция — по нему.
- `zone_beasts.weight` сейчас не читается: выбор вида в `PickPack` равномерный по количеству. Учитывать `weight`
  (количество × вес) — тогда «кто водится» в данных значит то, что написано.
