## Заметки на будущее

- `UIDocument.panelSettings`, назначенный сеттером из скриптовой сборки сцены, **не сериализуется** (`m_PanelSettings: {fileID: 0}`) — экран чёрный. Ставить через `SerializedObject` и сохранять сцену.
- `unity command script run` (не `run_script`), `editor.playmode start/stop` (не `editor_play`), `set_auto_tick --enabled`.
- USS и текстуры подхватываются только после `AssetDatabase.Refresh`: правки на диске при неактивном редакторе не импортируются сами.
