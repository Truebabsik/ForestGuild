## Итерация 2 — связность, ночь, визуал

Сделано после первого прогона:

- **Один человек — одно дело.** `DayPlan.IsBusy` + `RosterPanel.SetBusy`: занятый житель гаснет и не выбирается. Отряд убирается кнопкой «×», работники деревни — общей кнопкой.
- **Лимит два отряда** (`DayPlan.MaxParties = 2`), третья попытка даёт тост «Больше 2 отрядов деревня не поднимет».
- **Намерение отряда** выбирается кнопками «Сбор / Избегание / Чистка» и уходит в `PartyAssignment.Behavior`.
- **Работы в деревне**: «В ДЕРЕВНЮ» отправляет жителя на частокол, 1 человеко-день = +2 прочности (`DayFlow.RepairPalisade`).
- **Деревня на карте**: узел с иконкой, соединён ребром с зоной-воротами, состояние — прочность частокола.
- **Ночь объясняет себя**: на каждую зону с тварями строка «N твар., съедено корма X, кристаллов Y, голодных Z», в конце — «В лесу тварей: N, кристаллов на земле: M».
- **Иконки зон** (Agnes, 7 штук: шесть зон + деревня), сжаты до 128×128, лежат в `FG/Assets/UI/Art/Icons/`.
- Сообщения переехали из полноэкранного отчёта в тост над нижней панелью.

Проверено: `dotnet run --project tools/sim -- --selfcheck` → **14 проверок, код 0** (добавлены «village workers repair palisade» и «night report explains feeding»); в Play Mode пройден план «два отряда + 1 в деревне», третья попытка отбита лимитом, день закончен — отчёт ниже.

## Итерация 3 — закрытая информация и нарратив зоны

По замечанию из `ui.md`/`design.md` §6.5:

- **Точных чисел зоны больше нет.** Узел карты показывает слово: «?» (не разведано), «тихо», «следы»,
  «неспокойно», «гнездо» (`ZoneKnowledge.Mood` в ядре, UI ничего не решает сам).
- **Слухи.** `ZoneState.Sightings` — строки «день N — что видели». Пишутся из ядра: при встрече
  («отряд столкнулся с искромётом — отошли / приняли бой / ранили человека») и при появлении гнезда.
  В карточке видны последние три.
- **`zone_lore.csv`** (`zone_id; field; text`, поля `look/beasts/finds/special`) — 24 строки на шесть зон.
  Загрузчик падает, если у зоны нет любого из четырёх полей.
- **Карточка зоны** переписана: картинка 640×360, название, строка «окраина · дорога 1,5 ч · сейчас: следы»,
  нарратив, «кто водится», «что найти», «особое», «слухи». Неразведанная зона показывает только дорогу
  и соседей.
- **Отладочный режим** — тумблер «числа» в нижней панели: твари с количествами, кристаллы, корм,
  опыт гнезда, тревога. Проверено: при включении в карточке появляется строка «отладка: …».
- **Иллюстрации зон** — шесть штук через Agnes, `FG/Assets/UI/Art/Zones/*.jpg` (640×360, ~40 КБ).

ночь без точных чисел и не больше шести строк, «1280×720» → «1920×1080», битый пример «29%/час» → 8%,

## Итерация 4 — каркас фаз (ui.md §3)

- **HUD**: «ДЕНЬ N · ФАЗА | частокол X/Y | до волны: N дн.» — постоянная строка сверху.
- **Четыре фазы** как состояния экрана: Утро (карта, ростер, план) → День (лог вылазки) → Вечер (сводка
  добычи и раненых) → Ночь (жизнь леса) → Утро следующего дня. Каждая фаза — своя панель с одной кнопкой
  перехода.
- **`DayFlow` разделён**: `RunExpeditions` (день идёт, но день не сменяется) и `RunNight` (лес живёт,
  день +1). `RunDay` остался для консольных прогонов. Проверено тестом «day does not advance, night does».
- **Ночной отчёт без чисел** (`ui.md` §7): «Вулканические ключи: твари кормятся», «Каменный лог: голодные —
  кто-то уйдёт к деревне» вместо «1 твар., съедено корма 1».
- Кнопка «ПОДПИСАТЬ ПРИКАЗ» переводит Утро в День; модал-документ (§4.8) ещё не сделан.
- Из `AgentScripts` удалены устаревшие пробы, оставлены `BuildScene`, `FixPanelSettings`, `PhaseStep`, `RefreshUi`.

Проверено: 18 проверок `dotnet run --project tools/sim -- --selfcheck` → код 0; в Play Mode пройден цикл
Утро → День → Вечер → Ночь → Утро (HUD: «ДЕНЬ 1 · УТРО … до волны 20» → … → «ДЕНЬ 2 · УТРО … 19»),
скриншоты `docs/images/ui/step1/morning.png`, `day.png`, `evening.png`, `night.png`.

## Заметки на будущее

- `UIDocument.panelSettings`, назначенный сеттером из скриптовой сборки сцены, **не сериализуется** (`m_PanelSettings: {fileID: 0}`) — экран чёрный. Ставить через `SerializedObject` и сохранять сцену.
- `unity command script run` (не `run_script`), `editor.playmode start/stop` (не `editor_play`), `set_auto_tick --enabled`.
- USS и текстуры подхватываются только после `AssetDatabase.Refresh`: правки на диске при неактивном редакторе не импортируются сами.
