## Итерация 2 — засада и 17 проверок контракта

Коммит `…` (этот). Вопрос владельца «кто бьёт первым и перенесена ли засада» вскрыл две ошибки переноса
и одно устаревшее число в самом контракте.

**Исправлено в `Battle.cs`:**

- обнаружение — два **независимых** броска (было «сначала отряд, при провале тварь»: отряд заставал
  в 50 % боёв вместо 15 %);
- шанс твари учитывает `speed` (был 0.5 всегда вместо 0.7 у вора);
- удар из засады обходит не только броню, но и закалку; читаются все флаги `ambush_*`, `target_random`,
  `alert_bonus`;
- формулы вынесены в чистые `HitChance`, `PenaltyFactor`, `WeaponHit`, `BeastHit`; цикл боя один —
  `ResolveFighters` (`Resolve` для ростера, `ProbeFighter` для калибровки);
- `--battle` мерил 200 подряд идущих сидов: они давали 75,5 % там, где честно 66 %. Сиды разнесены
  (`seed × 7919 + 13`), выборка 1000.

**Чем проверено**

1. `dotnet run --project tools/sim -- --selfcheck` → **66 проверок, все ok, код 0**. Закрыты 16 из 17
   пунктов контракта §11; п.12 («плоская кривая в окне ±10 % HP») заменён на «крутизну» — он противоречит
   §10.6 того же контракта (ADR-0046).
2. `--curve` (проба без навыков, 4000 боёв на уровень): h1 **10,5** % / h2 **51,2** / h3 **86,8** /
   h4 **98,2** / h5 **99,8** (Python-прототип: 9,7 / 49,0 / 86,4 / 98,2 / 99,8). Без засады h2 58,6 %.
   Доли засад: отряд 15,4 %, тварь 35,2 %. Шансы: отряд 50 %, вор 70 %.
3. `--battle` (живой ростер): Хильда против вора 60,2 %, Скади 94,9 %, Брунни 99,2 %; Хильда против
   костяного бегуна 5,0 % — «дубиной не взять».
4. `--days 21`: 14 тварей, волна 10, частокол 0/10 — точка сместилась после новых тварей, требует
   отдельной калибровки.
5. Play Mode: модал встречи показывает стаю «Осколочник (стая из 2)», HUD «осталось 470 мин», слово
   риска из `Battle.Estimate` (`docs/images/ui/step1/encounter-pack.png`).

**Что всплыло в контракте:** §10.3 и `STATUS.md` обещали h2 35,9 % — это прогон до финальной калибровки;
тот же Python-скрипт сейчас даёт 49,0 %. Засада в §6.1 была описана порогом без бросков — текст заменён
на правило с независимыми бросками (ADR-0045).
